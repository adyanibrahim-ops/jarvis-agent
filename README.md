# 🤖 JARVIS — Personal AI Assistant

A Python-based personal AI assistant designed to provide an interactive
AI experience through conversation, tools, memory, and desktop functionality.

> 🚧 This project is actively under development.

## ✨ Current Features

- 🧠 AI-powered conversations
- 💻 Desktop application interface
- 🛠️ Modular application structure
- 💾 Project memory system
- ⚙️ System interaction capabilities
- 🔌 LLM API integration
